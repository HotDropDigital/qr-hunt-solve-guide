# QR Hunt Solve Guide

A click-through guide to past Utah Treasure Hunts QR Code hunt checkpoints: the clue, how it was solved, where the plaque was, the plaque question, official hints and the dead ends. Pick a year, then a QR, or browse by technique.

Live site: https://zachbmarshall.github.io/qr-hunt-solve-guide/

The page is a single `index.html` plus a `media/` folder, generated from a private knowledge base. Each solve is laid out as numbered steps, with the clue images, photos, videos and links that explain them. Hunter and team names and chat links are not included, and every image was reviewed to leave out faces, usernames and private messages. Organizers and sponsors are named because they are public parts of the hunt. This guide is not affiliated with the hunt organizers.

The season that is still running is password-locked: its solves are not in this repository or its history, and the page loads them from a private database only after the password is entered.
